# 居住观察 · 70城房价指数

双击 `index.html` 即可使用。页面内嵌全部数据，无需安装、联网或启动服务器；也可将 index.html 放到任意静态网站托管服务。

## 数据覆盖

- 2021-09 至 2026-08，连续60个月。
- 国家统计局70城 × 新建商品住宅/二手住宅，共8400条城市月度记录、16800个原始指数数值。
- 最新发布：2026-09-15；本次核验：2026-09-29。
- 保留环比（上月=100）、同比（上年同月=100）；未收集面积分类指数和年内累计平均指数。
- 这不是该统计项目的全部历史，未覆盖2021-09以前。

## 功能

月份、住宅类型、环比/同比切换；最多4城历史曲线；起止月份筛选；涨跌城市数量历史分布；70城图谱；搜索、排序、新旧房同表对照；全量中文CSV导出；逐月官方来源链接。适配桌面和手机。

## 文件

- index.html：独立离线应用，直接打开。
- app.template.html：应用源模板，数据占位符由脚本替换，勿直接作为应用使用。
- data.json：完整结构化数据和来源元信息。
- housing70.csv：规范化原始数据，UTF-8 BOM；new=新建商品住宅，resale=二手住宅。
- sources.json：逐月来源、发布时间、原始内容SHA-256。
- raw/：60个月原始官方网页快照（网页引用的图片/样式未离线保存）。
- update_data.py：仅依赖Python 3标准库的采集与重建脚本。

## 更新

在本文件所在目录执行：

```sh
python update_data.py
```

需联网。脚本自动遍历国家统计局数据发布索引，发现可获取的月度发布页；已下载月份复用缓存。要重新核验历史页面的修订，运行 `python update_data.py --refresh`。仅从现有来源和缓存重建：`python update_data.py --cached-sources`。

脚本会覆盖 index.html、data.json、housing70.csv、sources.json；请先备份自定义改动。只修改 app.template.html，再重新生成页面。页面不是后台定时更新服务；本次也未部署公网网站。

更新时校验：文章标题与目标月份一致、每月每类70个不同城市、全局70城集合、连续月份、唯一月份、预设指数异常范围。异常将抛出错误，停止生成，不以0补缺。官方改版、非HTML表格、旧月份从发布索引移出时，需要维护采集逻辑；请检查更新后的覆盖范围。结构校验不等于逐个数值人工复核。

## 口径与限制

涨跌幅=原始指数−100；99.8表示−0.2%。均值为70城等权算术平均，不是全国加权指数。2026年1月官方统计基期更换为2025年，本应用不拼接定基指数。公布指数精度为一位小数，持平是公布精度下持平；官方规定城市当月无成交时视为价格水平无变动。指数不能转化为绝对房价，也不能直接代表某一楼盘或住宅。分析为描述性统计，不构成投资建议。
